# 円高・円安どっち（endaka-enyasu）

1ドル＝○円が変わったら、円高？円安？ 両替・海外旅行・輸入・輸出・日本に来る旅行者の場面で、円とドルの額を計算して答え、正解したら「円高？円安？」も選ぶ1日5問の学習ゲーム。

遊ぶ: <https://satou-aaaaa.github.io/endaka-enyasu/>

- 中身は日本銀行「教えて！にちぎん」の「円高、円安とは何ですか？」（<https://www.boj.or.jp/about/education/oshiete/intl/g18.htm>）と「為替相場（為替レート）とは何ですか？」（<https://www.boj.or.jp/about/education/oshiete/intl/g17.htm>）で確かめたことだけ。輸出・輸入・旅行の答えは、その定義から円とドルの額を計算して決めています。
- レートと値段はすべて練習用の作り話です。実際の相場や予想は扱いません。両替の手数料は考えません。
- このゲームは投資の助言や、公式の情報の代わりではありません。円高・円安のしくみは日本銀行の資料で確かめてください。
